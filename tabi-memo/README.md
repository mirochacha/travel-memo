# 旅メモ

旅行先でスマートフォンを取り出し、音声またはテキストで数十秒以内に感想を保存して、後から見返せる軽量PWAです。ログインや外部API、サーバー、クラウドデータベースは使わず、旅メモは端末内だけに保存します。

## できること

- 日本語の音声認識結果を確認・修正して保存
- テキストメモを保存
- 音声そのものを録音して保存（対応ブラウザ）
- 日付ごとのメモ一覧、詳細表示、編集、削除
- 一度読み込んだアプリをオフラインで起動
- ホーム画面への追加

## ファイル構成

```text
tabi-memo/
├─ .openai/hosting.json   # 静的ホスティング設定
├─ README.md
└─ dist/
   ├─ index.html          # 画面構造
   ├─ style.css           # モバイルファーストのデザイン
   ├─ app.js              # 音声・録音・IndexedDB・画面操作
   ├─ manifest.json       # PWA設定
   ├─ sw.js               # オフラインキャッシュ
   └─ icons/              # PWAアイコン
```

## ローカルで動かす

Service Workerやマイクは `file://` では動作しないため、localhostで配信してください。

```bash
cd dist
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。Pythonがない場合は任意の静的ファイルサーバーでも構いません。

## スマートフォンで使う

公開先はHTTPSにしてください。アプリを開き、中央の「今の感想を話す」を押してマイクを許可します。認識結果を必要に応じて直し、「保存する」を押します。「テキストで書く」なら音声認識を使わず保存できます。「音声をそのまま残す」では、録音データ自体を端末内に保存します。

## ホーム画面に追加する

- iPhone / iPad: Safariの共有ボタンから「ホーム画面に追加」
- Android: Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」

表示されない場合は、HTTPSで開いていることと、ブラウザがPWAインストールに対応していることを確認してください。

## 音声認識と録音の制限

音声認識は `SpeechRecognition` / `webkitSpeechRecognition` を使用します。ブラウザやOSによって未対応の場合があり、認識処理にインターネット接続が必要な場合もあります。非対応時や失敗時も、テキスト入力と対応ブラウザでの音声録音は利用できます。録音は `MediaRecorder` を使用するため、こちらもブラウザによって利用可否や保存形式が異なります。

マイクは音声認識または録音中だけ利用し、録音終了時や画面を閉じた時点で停止します。

## データ保存とプライバシー

メモ本文、入力方法、作成日時、更新日時、録音BlobはブラウザのIndexedDBに保存されます。外部サーバーへ送信しません。ブラウザのサイトデータを削除すると旅メモも消えるため、必要な記録を残している場合はサイトデータを削除しないでください。

## オフライン利用

初回表示時にアプリ本体をService Workerへキャッシュします。その後はオフラインでもテキスト入力、端末内への保存、保存済みメモの閲覧・編集・削除ができます。音声認識は利用環境によってオンライン接続が必要です。

## 今後について

将来的には、ユーザーが明示的に選んだ場合に限り、保存した旅メモをもとにAIでブログ記事を作る機能を追加する予定です。現段階では記録機能だけを実装しており、AI機能や外部送信はありません。
